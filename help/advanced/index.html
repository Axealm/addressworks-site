詳細設定

検証の対象

請求先住所もチェックする（初期値: オフ）

配送先と別の請求先住所が入力された場合に、配送先と同じ設定で請求先も検証します。エラーは請求先の欄に表示されます。請求先が海外（日本以外）の場合は検証しません。

日本語を含まない住所は検証をスキップする（初期値: オン）

住所の全欄（氏名・市区町村・住所・建物名）が英数字と記号だけの場合、海外購入者とみなし、郵便番号照合を含む検証をすべてスキップします。オフにすると、日本語以外の入力は「英語（ローマ字）入力」としてエラーになります。

配送不要の商品だけのカートは検証をスキップする（初期値: オン）

デジタル商品やサービスなど、配送が不要な商品だけの注文では住所を検証しません。配送が必要な商品が 1 つでもあれば検証します。

検証しないケース（固定）

以下は設定にかかわらず検証しません。

  • 配送先の国が日本以外
  • カートの段階（住所入力前）
  • 本アプリを一時停止中、または月間の検証件数が上限に達した後（プラン）

設定のエクスポート／インポート

「エクスポート」で現在の設定を JSON として書き出せます。別のストアで「インポートする JSON を貼り付け」に貼って保存すると、同じ設定になります。JSON に不明な項目があっても無視され、足りない項目は初期値になります。

一時停止と再開

ホームの「住所チェックを無効にする」で、設定を保持したまま検証を止められます。「有効にする」で再開します。アンインストールせずに様子を見たいときにお使いください。
