郵便番号・住所の検証

管理画面「郵便番号・住所」の各項目です。すべて購入者の配送先住所が対象です（請求先も対象にするには 詳細設定）。

郵便番号

郵便番号と住所の照合（初期値: オン）

郵便番号から日本郵便のデータで「都道府県・市区町村・町域」を引き、入力された都道府県・市区町村・住所と比べます。町域名が市区町村欄にはみ出していても、連結して一致すれば通します。

入力例 結果
150-0001 / 東京都 / 渋谷区 / 神宮前1-2-3 通過
150-0001 / 東京都 / 渋谷区 / 神前1-2-3 「郵便番号150-0001の住所は「東京都渋谷区神宮前」で始まる必要があります。住所をご確認ください。」
150-0001 / 神奈川県 / 渋谷区 / 神宮前1-2-3 都道府県欄にエラー（期待値は東京都）

事業所の個別郵便番号（例: 060-8621）にも対応しています。町域を持たない郵便番号（「〇〇町一円」など）は市区町村までを照合します。

存在しない郵便番号の検出（初期値: オン）

日本郵便のデータにない郵便番号をエラーにします。

入力例 結果
214-0024 「この郵便番号は存在しません。ご確認ください。」
1500001（ハイフンなし）、１５０－０００１（全角） 7 桁として読み取り、通常どおり照合します

番地・町名

番地抜けの検出（初期値: オン）

住所欄に数字（丁目・番・号）が含まれない場合にエラーにします。漢数字（一丁目二番三号）も数字として認識します。町域が「一円」などで番地を持たない地域は対象外です。

入力例 結果
神宮前 「番地が入力されていません。〇丁目〇番〇号まで入力してください。」
神宮前一丁目二番三号 通過

町名なし（数字のみ）の検出（初期値: オン）

住所欄が数字と記号だけの場合にエラーにします。

入力例 結果
1-2-3 「町名が入力されていません。町名から番地まで入力してください。」

表記ゆれ

表記ゆれの検出（初期値: オン、「違いは許容する」もオン）

市区町村・町域の表記が公式と異なる場合の扱いです。

  • 許容する（初期値）: ヶ/ケ/が/ガ、っ/つ、の/ノ/之、旧字体と新字体の違いは同じものとして照合し、エラーにしません。
  • 許容しない: 公式表記と完全に一致しない場合、「正式な表記は「茅ヶ崎市」です。ご確認ください。」のように案内します。
入力例（253-0001） 許容する 許容しない
茅ケ崎市 通過 市区町村欄にエラー（正式表記「茅ヶ崎市」）

エラーの優先順位

同じ欄に複数の問題がある場合、1 件だけ表示します。順序は「存在しない郵便番号 → 全角数字 → 環境依存文字 → 英語入力 → 町名なし → 郵便番号と住所の不一致 → 表記ゆれ → 番地抜け → 文字数超過 → 禁止フレーズ → 建物名の連結」です。購入者が 1 つ直すと次の問題が表示されます。

郵便番号データの更新

日本郵便が毎月公開するデータ（住所の郵便番号・事業所の個別郵便番号）を月 1 回取り込み、検証関数を更新します。更新日は 更新履歴 に記載します。
