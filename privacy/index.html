プライバシーポリシー

アドレスワークス（以下「当方」）は、Shopify アプリ「住所チェック＆整形」（以下「本アプリ」）の提供にあたり、以下のとおり情報を取り扱います。

1. 購入者（店舗のお客様）の情報について

本アプリのチェックアウト検証は、Shopify のプラットフォーム内（Shopify Functions）で実行されます。購入者が入力した氏名・住所・電話番号・メールアドレスは、当方のサーバーに送信・保存されません。 検証の結果（エラー文）だけが Shopify のチェックアウト画面に表示されます。

注文件数の集計のため、Shopify から注文作成の通知（Webhook）を受け取りますが、受け取る項目は注文 ID と作成日時のみです。購入者の個人情報は含まれません。

2. 店舗（加盟店）から取得する情報

情報 目的 保存先
ストアのドメイン（例: example.myshopify.com）、アクセストークン アプリの動作、設定の保存、Shopify API の呼び出し 当方のデータベース（Cloudflare D1）
本アプリの設定内容と変更履歴 検証ルールの適用、設定画面の表示 店舗のメタフィールド（Shopify）と当方のデータベース
月間の検証件数、プラン、課金状態 上限の管理、請求 当方のデータベース
店舗の連絡先メールアドレス（Shopify に登録のもの） 上限到達などの通知メール 当方のデータベース（アンインストール時に削除）
管理画面へのアクセス記録（送信元 IP のハッシュ値、日時、種別） 不正アクセスの検知 当方のデータベース（90 日で削除）

3. 利用する外部サービス

  • Shopify（アプリの実行基盤、課金）
  • Cloudflare（管理画面サーバーとデータベースのホスティング。データは Cloudflare のネットワーク上に保存されます）
  • Brevo（店舗向け通知メールの送信）
  • GitHub（本サイトのホスティング。本サイトはアクセス解析や Cookie を使いません）

当方は、上記以外の第三者に情報を販売・提供しません。

4. 保存期間と削除

  • アプリをアンインストールすると、アクセストークンは直ちに無効化し、店舗データは Shopify からの削除要求（shop/redact Webhook）を受けて削除します。
  • 購入者データは保持していないため、購入者からの開示・削除要求（customers/data_request、customers/redact）に対しては「該当データなし」として応答します。
  • アクセス記録・処理失敗の記録は 90 日で自動削除します。
  • データベースのバックアップは暗号化して 90 日間保持します。

5. 安全管理

通信はすべて TLS で暗号化します。Shopify からの Webhook は署名を検証します。秘密情報（API キー等）はコードに含めず、実行環境の秘密変数に保存します。
